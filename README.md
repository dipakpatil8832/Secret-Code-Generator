🔐 Secret Code Generator

A simple web application to **encode and decode messages** using a Caesar cipher-style shift. Users can input a message, set a shift value, and instantly see the encoded or decoded result. Perfect for learning basic cryptography or having fun with secret messages.

## Features

- Encode messages by shifting letters by a custom value  
- Decode messages to reveal the original text  
- Clear messages with a single click  
- Preserves letter case and ignores non-letter characters  
- Clean, centered, and responsive design  

## Technologies Used
-**Python** - main logic
- **HTML** – Page structure  
- **CSS** – Styling and layout  
- **JavaScript** – Encoding and decoding logic
